# Prompt: Chart Show Glossary

**Target file:** `docs/agentic/context/chart-show-glossary.md`

---

## Paste this into ChatGPT:

```
I'm building an AI system that writes content for a weekly radio chart show. It needs a glossary of industry terminology so it can use the right language naturally.

Please create a glossary covering these categories. For each term, give: the term, a brief definition, and an example of how it's used in context (either in a script or in chart discussion).

## Chart Terminology
- Chart position / chart placing
- New entry / debut
- Climber / riser
- Faller / slider
- Non-mover / holds
- Re-entry / return
- Peak position / new peak
- Weeks on chart / chart run
- Consecutive weeks at #1
- Knocked off / dethroned
- Bubble (just outside the chart)
- Straight in (enters high without climbing)
- Hot shot (fastest riser)
- Movement delta (positions gained/lost)

## Radio Broadcast Terminology
- Cue / out-cue
- Back-announce / back-anno
- Segue
- Bed (background music under speech)
- Sting / jingle
- Talk-up (talking over track intro)
- Link (speech between tracks)
- Sweep (running multiple tracks without breaks)
- Format clock (show structure/timing)
- Drop (short audio clip/sound effect)
- Liner (short pre-recorded phrase)
- Rotation (how often a track is played)
- Power play / heavy rotation
- Breaker (new track getting trial plays)

## Show Structure Terms
- Countdown (the ranked reveal format)
- Rundown (listing positions sequentially)
- Recap (summarising positions already revealed)
- Tease / tease forward (previewing what's coming)
- Reveal (announcing a position)
- Build-up (creating anticipation before a reveal)
- Payoff (the satisfying conclusion — usually #1)
- Cold open (starting without preamble)
- Outro / sign-off

## Social/Promotional Terms
- Chart drop (the moment the chart is published/revealed)
- Spoiler (revealing positions before the show)
- Chart graphic / chart card (visual asset)
- Engagement hook (line designed to provoke comments/shares)
- CTA (call to action)
- Alt text (image description for accessibility)

Format as a markdown glossary. Group by category. Keep definitions concise (1 sentence) and examples natural (as they'd appear in a script or post).
```
