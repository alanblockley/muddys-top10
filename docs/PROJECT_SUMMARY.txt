FRONTEND CONFIGURATION:
════════════════════════════════════════════════════════════════

The frontend HTML contains a placeholder:
  const API_BASE = '%%API_ENDPOINT%%';

During deployment, deploy.sh:
1. Reads frontend/index.html
2. Replaces %%API_ENDPOINT%% with actual API Gateway URL
3. Uploads configured HTML to S3
4. Invalidates CloudFront cache

This ensures the frontend always points to the correct API!
