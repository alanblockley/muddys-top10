# Prompt: Radio Read Examples

**Target file:** `docs/agentic/context/radio-read-examples.md`

---

## Paste this into ChatGPT:

```
I need to create a set of "golden examples" of radio reads for my weekly Top 10 chart show. These will be used by an AI as style reference — it should aim to produce output that sounds like these examples.

The show is DJ Toohey's Top 10 countdown at Muddy's Music Cafe (Second Life internet radio). Co-host is JP. Show airs Saturday 2am SLT.

I'm going to provide you with either:
(a) Past scripts/reads I've written or used that I was happy with, OR
(b) A description of what "good" sounds like, and I'd like you to write example reads that match

For each type of read, I need 2-3 examples that represent the quality and tone I'm targeting:

## Types needed:

1. **Show intro** — the opening 30-60 seconds that sets up the countdown
2. **Top 10 intro** — transitioning into the actual countdown ("let's get into it")
3. **Position read (lower chart, 10-6)** — brief, conversational, one position
4. **Position read (mid chart, 5-4)** — slightly more energy
5. **Position read (top 3)** — building tension
6. **Position read (new entry)** — different flavour for a debut
7. **Position read (biggest climber)** — celebrating movement
8. **Top 5 recap** — quick summary of 5-through-10 before moving to the top 5
9. **Top 3 recap** — building to the #1 reveal
10. **Number one reveal** — the climax moment
11. **Outro/sign-off** — wrapping the show

For each example, note:
- Why it works
- What makes it sound like THIS show (not generic radio)
- Approximate word count / delivery time

---

After I provide my input (examples or descriptions), format the output as a markdown reference document with:
- Each read type as a section
- 2-3 examples per type
- Annotations explaining what makes each one effective
- A "pattern notes" section summarising common structures across the examples
```

---

## Notes

- This is the most valuable context file for radio read quality. Real examples trump rules.
- If you have transcripts, scripts, or even rough notes from past shows — paste them in.
- If you don't have written scripts (it's improvised), describe what you typically say and ask ChatGPT to write examples in that style, then edit until they feel right.
- Even 1 good example per type is better than none. You can add more over time.
